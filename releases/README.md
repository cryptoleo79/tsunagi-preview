# Release assets

Binary assets are attached to [GitHub Releases](https://github.com/cryptoleo79/tsunagi-preview/releases),
not committed to this repository tree. Download checksums and instructions from the **same tag**
as the chosen binary.

At the **2026-10-27** check, GitHub marked the
[October 2026 portable follower](https://github.com/cryptoleo79/tsunagi-preview/releases/tag/v2026.10.05-preview-portable-x86_64)
**Latest**. Its assets are `tsunagi-preview-v2026.10.05-linux-x86_64`, `SHA256SUMS`,
`PROVENANCE-MANIFEST.md`, and an attached `INSTALL.md`. It is not qualified by that release for
block production. Follow its own installation instructions.

The [June 2026 historical producer release](https://github.com/cryptoleo79/tsunagi-preview/releases/tag/v2026.06.18-preview)
has different assets: `tsunagi-node-v2026.06.18-preview-linux-x86_64`, `SHA256SUMS`, `cockpit`,
and `forge.env.sample`. The June producer commands and 41-block status snapshot do not describe
the October follower or current operations.

See [`../RELEASES.md`](../RELEASES.md), [`../DOWNLOAD.md`](../DOWNLOAD.md), and
[`../SECURITY.md`](../SECURITY.md) for release scopes and verification guidance.
